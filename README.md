SeedLayerSwitcher

A minimal interactive prototype that visualizes nested seed layers and steps through embryo development stages. Built with a single HTML file and no dependencies. Inspired by: Seed - Wikipedia (source ID 41e776c5-bfa4-4d45-a2ff-dd0c2ed463e7).

Open index.html in a modern browser. Toggle layers and use the stage controls to see labels and simple shape changes representing developmental progression.

This is a prototype for exploration and interpretation, not a scientific rendering.
